# ADR-0022：试卷题号化与答卷覆盖度核对

- **状态**：Accepted
- **日期**：2026-10-18
- **相关 ADR**：ADR-0004（答卷抽取必须可重建）、ADR-0009（不自动判分）、
  ADR-0016（值列只放事实）、ADR-0017（失败=执行层面，如实记录）、
  ADR-0020（完成条件=模型写完）、ADR-0021（收尾事实与逐卷落盘）

## 背景（Context）

ADR-0020 放开 `-n` 之后，"跑很久"变成常态，于是"**模型到底答到第几题**"成了最该显示的事实。
在此之前只有间接线索：答卷字符数（ADR-0021）。实测（F27）证明这个线索不够——旧口径 `-n 1024` 的
**6 份答卷全部未答完**（都在半句上截断），而新口径 `-n -1` 的 **8 份答卷全部 30/30**；
但如果只看"字符数"，13000 字符的截断卷与 13000 字符的完整卷长得一模一样。

要机械核对"答完了没"，需要一个可判定的依据。检查两份试卷后发现：

| 试卷 | 题目是否自描述 | 后果 |
|---|---|---|
| `paper_1` | 每题都有题号标题（`### K1｜概念与因果`，共 30 个） | 可精确核对 |
| `paper_2` | 只有 `一、知识问答（5 题）` 这样的**题数声明**，题面无编号 | 只能用"答卷侧有没有编出 1~5 条"去反推——**启发式** |

启发式意味着"不按题号作答但内容完整"的答卷会被误报为未答完。这不是可接受的地基：
一个会误报为"失败"的检查，比没有检查更糟。

## 决策（Decision）

1. **把 `paper_2` 改成 `paper_1` 的格式**（题号化）：`## A. 知识问答` + `### K1｜短标题` 逐题标题，
   **题面文字一字未改**（30/30 逐字比对通过，见证据表）；三处类名按 `paper_1` 的措辞统一
   （代码生成→编程能力、写作/总结→写作与总结、长上下文→长上下文阅读）。旧版归档在
   `test_content/real_test/archive/paper_2.v1`（`paper_paths()` 只认试卷目录下的 `paper_*`，归档不会被当成试卷）。
2. **核对机制零资产**：新增 `arena/coverage.py`（纯文本函数，不依赖 arena 其它模块）——
   试卷侧提取题号声明（`### K1｜` / `K1：`），答卷侧核对"行首是否引用了该题号"。
   不引入 `.expect` 清单之类的额外资产：试卷自己声明题号，够用。
3. **它是 EXAM 的收尾步骤**：每卷抽完正文、写答卷文件时，文件头多一行
   `- 题目覆盖: 覆盖 30/30（按试卷题号核对）`；整轮收尾再上报一帧进度
   `答卷覆盖 paper_1 30/30 · paper_2 30/30`（`fraction=None`，与 ADR-0021 的存活信号同源）。
4. **只报事实，不改 `ok`**：覆盖度**不**参与 `ok`、不写进 `paper_failures`、不进 JSONL schema。
   失败语义仍归 ADR-0017（超时/取消/非零退出/抽取失败）。理由：覆盖度是**答卷内容**的属性，
   不是执行的成败；把它当失败会把"没按题号写"记成"这一卷没跑成"。
5. **"无法判定"必须与"未覆盖"分开**：试卷没有题号、或答卷一个题号都没引用时，
   结论是 `覆盖无法判定（原因）`，**不是 0/30**，也不算失败。这一档专门用来避免
   "改版前的答卷"被误报——那时模型答的是旧版无题号试卷。
6. **配一个独立工具** `tools/check_completion.py`：对 `runs/`（含归档轮次）里已有的答卷复算覆盖度，
   不必重跑模型；退出码 1 **只**给"明确未覆盖"，"无法判定"记 warning 不失败。
   `--current-only` 按**当前协议索引**（`runs/arena_history.jsonl`）过滤轮次——不能按目录名排除，
   因为 ADR-0021 归档的是索引、run 目录仍留在 `runs/` 下。
7. **试卷改版按"窄口径"归档**：题号化后的**实测轮次**（2026-10-18 12:50 / 13:00）留在当前索引，
   改版前的那一轮（10:20 / 10:36，其 `paper_2` 答卷无法核对）移入
   `runs/archive/arena_history.pre-paper2-v2.jsonl`。`PROTOCOL_NAME` **不改**——它的职责是挡"负载参数与完成条件"
   不同的数字混进对比表，而试卷改版不影响 bench/PPL（对比表只收这两列）；旧索引移走后，
   `tools/check_completion.py --current-only` 成为干净的闸门（4 份答卷全 30/30，退出码 0）。
8. **明确不做**：判分（ADR-0009）、题目级内容解析、机读 `finish_reason`（工具不报停止原因）、
   把覆盖度落成记录字段（用户明确不要 schema 变更）、把试卷版本塞进协议名（见第 7 条的取舍）。

## 理由（Rationale）

- **先修数据，再修代码**：把"检查不准"的根因（试卷不自描述）消掉，比在代码里堆启发式与资产文件便宜得多。
  这一条把"要不要加题号清单资产"的取舍整个删除了。
- **可判定性优先于覆盖率**：宁可对一批答卷说"无法判定"，也不要给出一个会误报的比例。
  这延续了 ADR-0016"值列只放事实"与 ADR-0017"没有数字就说没有数字"的一贯取向。
- **核对与判分分离**：能机械核对"答到没有"不等于能判断"答得好不好"。前者是事实（本题的范围），
  后者需要评委与评分标准（仍未有 ADR，见 §10 下一层问题）。
- **同一套逻辑两处复用**：`arena/coverage.py` 同时被 EXAM 收尾与 `tools/check_completion.py` 使用，
  避免"软件里显示的"与"工具里复算的"两套判定漂移。

## 后果（Consequences）

### 实测证据（2026-10-18）

| 场景 | 结果 |
|---|---|
| `paper_2` 改版后的题面完整性 | 与归档旧版逐题比对：**30/30 题面逐字一致**（只新增标题行） |
| 试卷题号提取 | `paper_1` **30** 个题号；新版 `paper_2` **30** 个题号；旧版 `paper_2` **0** 个（⇒ 无法判定档） |
| 运行时收尾（quick 端到端，隔离产物目录） | 收尾行 `EXAM: 答卷覆盖 paper_1 1/30 · paper_2 2/30`；答卷头出现 `- 题目覆盖: 覆盖 1/30（…；按题号核对）`。quick 只给 64 token，1/30 与 2/30 是**如实**结果 |
| 新版 `paper_2` 在真实模型输出上可用（quick） | 同一轮里 `paper_2` 按题号被识别到 2 题（说明模型会跟着新题号作答），旧版格式下同类答卷是"未引用任何题号" |
| **真实档全卷核对（2026-10-18 12:50 / 13:00，本轮）** | Meta-Llama 与 Qwen-MOE **各两卷都 `30/30`**：收尾行 `EXAM: 答卷覆盖 paper_1 30/30 · paper_2 30/30`，答卷头 `- 题目覆盖: 覆盖 30/30（按题号核对）`。这是"新格式下模型答完整卷"的直接证据 |
| `tools/check_completion.py` 对 30 份既有答卷 | 完整 **6** · 未覆盖 **9** · 无法判定 **15**；未覆盖的全是旧口径 `-n 1024` 的截断卷（部分答到，故可按题号判定），无法判定的全是"未引用任何题号的旧格式答卷 + 30B 的 thinking 答卷"，**没有一份被误报为未覆盖** |
| 同上，`--current-only`（只核对当前协议索引） | 答卷 **4** 份全部 **完整 30/30**（完整 4 · 未覆盖 0 · 无法判定 0），**退出码 0**——改版前那一轮移入归档后，这条命令就是干净的机械闸门 |
| 回归 | quick 全程 26 s 级别无变化；`check_traceability.py` 通过（18 源文件 / 22 ADR） |

### 代价与残余限制

- **题号后紧跟中文字符不算引用**：`K3题是关于…` 因 `\b` 判定不成立而**不算**引用（Python 里中文字符也是
  单词字符）。这是刻意的保守选择——30B 的 thinking 答卷正是这种形态，把它算成"引用了"会得到虚假的高覆盖；
  代价是这类答卷落到"无法判定"。
- **改版前的答卷只能"无法判定"**：`runs/` 与归档里所有用旧版 `paper_2` 答的答卷都属于这一档
  （改版前那一轮的索引已移入 `runs/archive/arena_history.pre-paper2-v2.jsonl`，run 目录原样保留）。
  想精确核对这些历史答卷，需要把试卷目录指回归档（`--papers-dir test_content/real_test/archive`），
  而旧版本身没有题号 ⇒ 仍然"无法判定"。这是改版的真实代价，无法通过代码挽回。
- **改版只按"窄口径"归档，不换 `PROTOCOL_NAME`**：对比表只收 bench 与 PPL，二者与试卷无关；
  改版只影响 **EXAM 答卷**的跨版本可比性（旧版答卷不可与新答卷并列比较）。因此处理方式是
  "把改版前那一轮的**索引**移入 `runs/archive/arena_history.pre-paper2-v2.jsonl`"，
  而不是像 ADR-0021 那样重置整个协议。若将来要考"试卷版本也进协议名"，那是新 ADR 的事。
- **覆盖度不进记录**，因此 `--compare`/`HISTORY` 看不到它，只能从答卷文件头或工具里读。
  这是"不要 schema 变更"的直接后果，知情接受。
- 未验证：30B 在新版 `paper_2` 上的表现（按用户要求不跑 30B）；以及"模型完全不按题号作答"时的
  覆盖度判定（当前会落到"无法判定"，没有真实样本可供校准）。
